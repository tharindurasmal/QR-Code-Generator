# QR Code Generator

A simple React application that generates QR codes from text or URLs. Users can enter input, generate a QR code instantly, and download it as an image.

## Features

* Generate QR codes from text or URLs
* Download QR code as PNG image
* Clean and responsive UI

## Tech Stack

* React.js
* react-qr-code
* CSS

## Installation

```bash
npm install
npm start
```

## Usage

1. Enter text or URL
2. Click generate
3. Download QR code image
